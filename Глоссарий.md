# Глоссарий

Назад: [[MONE]]

- **Повторяемость (precision)** — насколько кучно ложатся повторные измерения одной точки. Случайный разброс не калибруется, но уменьшается усреднением (~1/√N).
- **Абсолютная точность (accuracy)** — насколько измерение близко к истине. Систематическая ошибка лечится калибровкой, пока стабильна.
- **Средняя / медианная ошибка** — среднее раздувается выбросами, медиана их прячет. Для разметки важна доля точек в допуске (напр. 95%).
- **СКП (σ)** — среднеквадратическая погрешность, типичный размер ошибки.
- **Предельная погрешность** — δ = t·m, t = 2; 2,5; 3 (СП 126, п. 7.7). При нормальном распределении 95% ≈ 2σ.
- **Бюджет ошибок** — раздача допуска по подсистемам; независимые ошибки складываются как √(Σ²).
- **Дрейф** — накопление ошибки у относительных датчиков (одометрия, IMU). Внешняя опора не дрейфует.
- **Трекинг** — непрерывное отслеживание положения во времени, в отличие от разового измерения.
- **Lighthouse** — система отслеживания Valve для VR: базовые станции прочёркивают пространство ИК-лазерными плоскостями, фотодиоды на объекте фиксируют момент прохода луча. Только для помещений.
- **Базовая станция / излучатель** — неподвижный источник сигнала-ориентира. **Приёмник** — фотодиоды на роботе.
- **Лазерный блок** — внешняя неподвижная система опоры (станции + приёмник), дающая роботу абсолютную координату.
- **Тахеометр** — прибор, измеряющий два угла и расстояние до точки → X, Y, Z. Роботизированный — сам наводится и следит за призмой.
- **Вынос в натуру** — перенос проекта (чертежа) на площадку.
- **Разбивочная основа / внутренняя разбивочная сеть** — закреплённые точки с известными координатами; робот работает от них, а не строит их.
- **Привязка** — совмещение системы координат прибора/робота с системой здания.
- **Плита перекрытия** — бетонная плита: пол этажа и потолок нижнего; рабочая среда робота.
- **Захватка** — участок, на который делят фронт работ (часть этажа).
- **ППГР** — проект производства геодезических работ.
